# Area 別 1 出撃あたり万能設計図削減量

> `node scripts/area-wildcard-efficiency.js` で自動生成。
> データ実体は [`data/area-wildcard-efficiency.yaml`](../data/area-wildcard-efficiency.yaml)。

任務 Normal の各 Area を 1 周したとき、何枚分の万能設計図相当を削減できるかの一覧。
2倍キャンペーン (multiplier=2) を前提とする。

## 結論一覧

| 主 Tier | Area | 高枠 + 低枠 + 低枠 | 計 / 周 | AP / 万能1枚 |
|:---:|:---:|:---|---:|---:|
| T2 | 4・5 | 6.8 + 5.1 + 5.1 | 17.0 | 0.588 |
| T3 | 7・8 | 10.72 + 8.04 + 8.04 | 26.8 | 0.373 |
| T4 | 10・11 | 16 + 12 + 12 | 40.0 | 0.250 |
| T5 | 13・14 | 21.68 + 16.26 + 16.26 | 54.2 | 0.184 |
| T6 | 16・17 | 24.6 + 18.45 + 18.45 | 61.5 | 0.163 |
| T7 | 19・20 | 32.12 + 24.09 + 24.09 | 80.3 | 0.125 |
| T8 | 22・23 | 41.16 + 30.87 + 30.87 | 102.9 | 0.097 |
| T9 | 25・26 | 54.64 + 40.98 + 40.98 | 136.6 | 0.073 |
| **T10** | **28・29** | **75.4 + 56.55 + 56.55** | **188.5** | **0.053** |

## 表の読み方

- **高枠 + 低枠 + 低枠**: 任務 Normal の 1 ステージは 3 カテゴリの装備をドロップする。
  内 1 枠だけドロップ率が約 1.33 倍 (4:3 比) に設定されており、残り 2 枠は等しい値。
  万能設計図と同 Tier 装備のサブドロップを **すべて万能換算** で合算したものを 3 枠別に表示。
- **計 / 周**: 上記 3 枠の合計 = 1 出撃で削れる万能設計図の総量。
- **AP / 万能1枚**: 万能設計図 1 枚相当を削るのに必要な AP (低いほど効率良い)。
- 同 Tier の 2 つの Area (例: 28 と 29) は **数値が完全一致**。違いはドロップカテゴリのみ。

## 計算式

カテゴリごとに以下を集計し、3 カテゴリ分を降順に並べる:

```
カテゴリ換算 = 万能ドロップ × multiplier
            + Σ (Tier装備ドロップ × multiplier × wildcard_rate[Tier])
```

`wildcard_rate` は [equipment-upgrade.md](./equipment-upgrade.md) のレート (T2=2, T3=3, …, T10=50)。
高 Tier ほど rate が急激に大きくなるため、サブドロップの寄与も含めて高 Tier Area が常に有利になる。

## primary 単体の貢献度

主 Tier 装備 (= 各 Area の "primary") の万能換算だけ抜き出した値。
**その Tier 装備が満タンになり不要になったとき、この分が「無駄ドロップ」になる**。

| 主 Tier | Area | primary 高 + 低 + 低 = 計 | total に占める比率 |
|:---:|:---:|:---|---:|
| T2 | 4・5 | 4.8 + 3.6 + 3.6 = 12 | 70.6% |
| T3 | 7・8 | 6.72 + 5.04 + 5.04 = 16.8 | 62.7% |
| T4 | 10・11 | 9.2 + 6.9 + 6.9 = 23 | 57.5% |
| T5 | 13・14 | 10.08 + 7.56 + 7.56 = 25.2 | 46.5% |
| T6 | 16・17 | 8 + 6 + 6 = 20 | 32.5% |
| T7 | 19・20 | 10.32 + 7.74 + 7.74 = 25.8 | 32.1% |
| T8 | 22・23 | 13.76 + 10.32 + 10.32 = 34.4 | 33.4% |
| T9 | 25・26 | 20.64 + 15.48 + 15.48 = 51.6 | 37.8% |
| T10 | 28・29 | 34.4 + 25.8 + 25.8 = 86 | 45.6% |

低 Tier ほど「primary 依存度が高い」(T2 で 70%) のに対し、高 Tier では万能ドロップとサブ Tier の寄与で **primary 比率が 30〜45% に下がる**。これが後段の「T10 装備満タン後も Area 28 が無駄でない」の根拠。

## T9・T10 装備が満タンになった後の周回効率

「T9・T10 装備はもう要らない」となった状態での 1 出撃あたり万能換算。
T9 装備が primary の Area 25・26 と T10 装備が primary の Area 28・29 では、
それぞれ primary 分が「無駄ドロップ」化するため値が下がる。
T8 以下の Area は primary がまだ必要なので **値は変化しない**。

| 主 Tier | Area | 通常 (全 Tier 必要) | T10 満タン後 | T9 + T10 満タン後 |
|:---:|:---:|---:|---:|---:|
| T2 | 4・5 | 17.0 | 17.0 | 17.0 |
| T3 | 7・8 | 26.8 | 26.8 | 26.8 |
| T4 | 10・11 | 40.0 | 40.0 | 40.0 |
| T5 | 13・14 | 54.2 | 54.2 | 54.2 |
| T6 | 16・17 | 61.5 | 61.5 | 61.5 |
| T7 | 19・20 | 80.3 | 80.3 | 80.3 |
| T8 | 22・23 | 102.9 | 102.9 | **102.9** |
| T9 | 25・26 | 136.6 | **136.6** | 85.0 |
| T10 | 28・29 | **188.5** | 102.5 | **102.5** |

### 読みどころ

- **T10 満タン後の Area 28・29 は 102.5** (T8 帯 102.9 と実質同等)。Area 28 を回り続けても T8 帯と遜色ないので、 **習慣で続けても損は少ない**。
- **T10 満タン後の最効率は Area 25・26 (T9, 136.6)**。T9 装備需要が残っていればそちらに切り替えると約 33% 効率アップ。
- **T9+T10 両方満タン後は Area 22・23 (T8, 102.9) が最効率**。Area 28・29 (102.5) を僅差で上回る。Area 25・26 は 85.0 まで落ちて 5 番手相当に。
- 興味深いのは、**T9 装備が primary になっている時の Area 25・26 (136.6) は、T10 を切ってサブだけになった Area 28・29 (102.5) より 1.33 倍効率が良い** 点。`T10 を切ったあとの Area 28・29 はサブ + 万能だけで T9 帯の primary 貢献を上回れない` 構造。
