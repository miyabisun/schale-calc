# オニア先生の黄金比

本リポジトリの育成目標プリセット `oniea_golden_ratio` の出典。

## 出典

- 紹介動画: [【素材バランス変更】ドロップ量大幅増加後の世界がどうなるのか予想　新旧比較と増加率　とりあえずの周回方針【ブルーアーカイブ】](https://www.youtube.com/watch?v=_kF8vcBwBwk)
- 配信チャンネル: [オニア先生のブルアカ攻略](https://www.youtube.com/@ONIABlue)

## 指針

ブルーアーカイブは月に複数の新生徒が実装され、さらに期間限定ボスが登場する。
任務 Normal 2倍キャンペーンは月に約 7 日しか来ないので、急な育成需要に備えて
**あらかじめ「よく使われるカテゴリ」の装備設計図を多めに在庫しておく** のが安全。

オニア先生は全生徒の装備要求から偏りを割り出し、以下の配分を黄金比として提案している。
この分の装備設計図を T1 完成品から T10 まで仕上げられる量を常備しておけば、
その月の急な育成需要をおおむね吸収できるという指針。

| 系統     | カテゴリ | 人数分 |
|----------|----------|-------:|
| 攻撃系   | 帽子     | 3 |
|          | 手袋     | 2 |
|          | 靴       | 4 |
| 防御系   | カバン   | 2 |
|          | バッジ   | 2 |
|          | ヘアピン | 4 |
| 特殊系   | お守り   | 1 |
|          | 時計     | 4 |
|          | ネックレス | 2 |
