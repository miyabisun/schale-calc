サイコロランの確定サイコロの使い方

復刻「我らオカルト研究会」（2026年10月7日から）のミニゲームで、確定サイコロの使い方を5通り比べました。普通のサイコロを200回振る遊び方を500パターン用意し、どの使い方でも同じ目の並びで試しています。あわせて、神名のカケラの期待値が最大になる使い方を計算で求め、手で追える使い方がどこまで届くかを調べました。

結論

4の確定サイコロを神名のカケラ12個のマスで使い、残りの回数で使い切れないほど持っていれば、カケラ8個のマスやスタートに止まるためにも使う（E「余りをカケラ8のマスとスタートで使う」）使い方で、神名のカケラが最も多く集まりました。

500パターンの平均は595.0個です。2位のB「4をカケラ12のマスで使う」より平均2.6個多く、A・D・Cより12.0〜63.0個多くなりました。

計算で求めた、期待値が最大になる使い方は、同じ500パターンで平均601.0個でした。状況ごとに判断が変わるため手で追うのは難しく、Eとの差は平均6.0個です。

最適な使い方との比較

次に出る目を知らずに、神名のカケラの期待値が最大になるように確定サイコロを使う方法を計算で求めました。最初の確定サイコロ16個の目も決まっていない状態から数えた期待値は602.7個です。この値は下限で、本当の最大値はこれ以上です。理由は下の「計算の方法」に書きます。

同じ500パターンで走らせると平均601.0個で、Bより平均+8.6個（95%信頼区間 +6.2〜+11.0個）多くなりました。E「余りをカケラ8のマスとスタートで使う」との差は平均+6.0個（95%信頼区間 +3.5〜+8.5個）です。

計算の方法

最後の1回から逆にたどって求めました。

  1. 遊んでいる途中の状況を「残りの普通のサイコロの回数・今いるマス・手持ちの確定サイコロ（目ごとの個数）」で表します。次に出る目は状況に含めません。
  2. 残り0回の状況では、手持ちを使い切る順番をすべて試し、カケラの期待値が最も大きい値を求めます。スタートで受け取る確定サイコロは、1〜6が同じ確率で出るものとして平均します。
  3. 残り1回の状況では、「普通のサイコロを振る」と「1〜6のどれかの確定サイコロを使う」のそれぞれについて、その後に取れるカケラの期待値を、すでに求めた状況の値から計算します。普通のサイコロは1〜6の目を同じ確率で平均します。期待値がいちばん大きいものを、その状況での判断とし、その期待値を状況の値とします。
  4. 残り2回、3回…と200回まで同じ計算を繰り返します。

手持ちの組み合わせは、個数が増えると急に増えます。そこで計算では手持ちを合計20個までとし、20個持っているときにスタートで受け取った確定サイコロは捨てました。実際に遊ぶときも「受け取った確定サイコロを使わずに取っておく」ことはできるので、求めた期待値は本当の最大値を超えません。これが下限と書いた理由です。上限を広げたときの期待値は次の通りで、18個から20個に広げても0.001個しか変わりませんでした。本当の最大値も、ほぼこの値と考えられます。

手で追える使い方への置き換え（E）

上の場面で最適な使い方が確定サイコロを使い始めるのは、手持ちが1個なら残りが7〜17回以下、2個なら残りが39回以下になってからです。持っている個数が多いほど早く使い始めます。普通のサイコロは約5回で1周するので、残りの周回で使い切れない分を、カケラ8個のマスやスタートで使っていると読めます。

そこで「手持ちの個数の5倍が、残りの普通のサイコロの回数以上になったら使う」という目安をBに足したのがEです。5倍という係数は、評価に使う500パターンと10,000パターンとは別の乱数で作った10,000パターン（seed 424242）で、3〜6倍を試して決めました。Eの手順は次の節にあります。

それぞれの使い方

普通のサイコロを振る前に、次の手順1と手順2を順に確かめます。当てはまった確定サイコロを使ったら、止まったマスでもう一度手順1から確かめます。どれにも当てはまらなければ、普通のサイコロを振ります。判断に使うのは、今いるマスと手持ちの確定サイコロ（Eでは残りの普通のサイコロの回数も）だけです。次に出る目は使いません。

手順2. 使い方ごとの追加の規則

  • A「4でスタートを狙う」：4を持っていてマス12（神名のカケラ8）かマス14（装備強化珠4）にいるときに、4を使ってスタートに止まります（マス12からはマス16の「2マス進む」を通ります）。4以外は手順1の用途にだけ使います。

  • C「スタートを積極的に狙う」：スタートにちょうど止まれる確定サイコロがあれば使います。止まれるのはマス11（クレジット300万）から5、マス12（神名のカケラ8）から4か6、マス13（オーパーツ4）から3か5、マス14（装備強化珠4）から2か4、マス15（レポート8）から1か3、マス17（装備強化珠7）から1です。候補が2つあるときは、4があれば4を、なければ大きい目を使います。

  • E「余りをカケラ8のマスとスタートで使う」：Bの規則に加えて、手持ちの確定サイコロの個数の5倍が、残りの普通のサイコロの回数以上になったら（たとえば手持ち3個なら残り15回から）、次の目も使います。まずマス12（神名のカケラ8）にちょうど止まれる目（マス6（装備設計図218）から6、マス7（オーパーツ4）から5、マス9（装備強化珠7）から3、マス11（クレジット300万）から1）、なければCと同じくスタートにちょうど止まれる目です。

手順3. 200回振り終えた後の使い切り方

手持ちの確定サイコロを使う順番をすべて考え、神名のカケラが最も多く取れる順番の1個目を使います。この順番では、途中でスタートに止まって受け取る確定サイコロは数えません。受け取ったら、その時点の手持ちで順番を考え直します。5通りとも同じ方法で使い切ります。

カケラの数が同じ順番が複数あるときは、次の順に決めます。

  1. スタートに止まる回数が多い順番
  2. スタートに止まるまでに使う確定サイコロの数が少ない順番（止まるたびに数えて合計します）
  3. 1個目の目が小さい順番

たとえばマス3（オーパーツ5）で4と5が残ったときは、5でマス8（カケラ12個）、続けて4でマス12（カケラ8個）に止まり、合わせて20個取れます。4を先に使うとマス7に止まり、次の5でマス12（カケラ8個）に止まるので8個です。そのため5を先に使います。
